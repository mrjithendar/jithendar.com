This Python tutorial for beginners goes from the first `print()` to a small FastAPI service with tests. Each topic starts with a small example you run on your own computer, then shows the same idea in [MOKS](/projects/moks), the Python SRE portal I run at `jithendar.com/moks`, which answers questions such as "Why is checkout returning 502 errors?" from Kubernetes, Prometheus and Loki evidence.

## 1. What Python is

Python is a programming language. You write instructions in a `.py` file, and the **Python interpreter** carries them out from top to bottom. MOKS uses it for a command-line tool, a web API, background workers and calls to language models.

*Standalone teaching example.* Save this as `hello.py`.

```python
# hello.py
name = "MOKS"
print("Hello from", name)
```

```text
$ python3 hello.py
Hello from MOKS
```

`python3 hello.py` starts the interpreter on that file. A line starting with `#` is a **comment**, which Python ignores. `name = "MOKS"` stores text under a name, and `print(...)` writes values separated by spaces.

### Indentation is part of the syntax

Python groups lines by **indentation** instead of braces: lines indented under an `if` belong to it.

*Standalone teaching example.*

```python
# indentation.py
pods_restarting = 3
if pods_restarting > 0:
    print("Some pods restarted")
    print("Check their logs")
print("Done")
```

```text
$ python3 indentation.py
Some pods restarted
Check their logs
Done
```

The colon ends the `if` line and starts a block; the indented lines run only when the condition is true, and `print("Done")` runs either way. Use four spaces per level, as MOKS does.

**Common mistake:** forgetting to indent the block.

*Standalone teaching example.*

```python
# bad_indent.py
pods_restarting = 3
if pods_restarting > 0:
print("Some pods restarted")
```

```text
$ python3 bad_indent.py
  File "/home/you/python-tutorial/bad_indent.py", line 4
    print("Some pods restarted")
    ^
IndentationError: expected an indented block after 'if' statement on line 3
```

Python refuses to run the file and points at line 4 (the comment on line 1 counts). The fix is four spaces before `print`.

### The language, the standard library and packages

**The language** is the syntax and built-in types. **The standard library** ships with Python (`json`, `pathlib`, `re`, `logging`, `asyncio`). **Third-party packages** are installed separately; MOKS's [`backend/pyproject.toml`](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/pyproject.toml) lists FastAPI, Pydantic, SQLAlchemy, HTTPX, LangGraph, boto3 and others. When a framework does something, I name it.

## 2. Setting up Python

MOKS declares `requires-python = ">=3.11"`, builds from `python:3.12-slim` and runs CI on 3.12. Use 3.12 if you can; everything here also works on 3.11. MOKS uses the standard `venv` and `pip` tools, not Poetry or uv.

A **virtual environment** is a folder with its own package list, so installs do not affect other projects or the system Python:

```bash
# working directory: your home folder
mkdir -p ~/python-tutorial
cd ~/python-tutorial
python3 --version
python3 -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
python --version
python -m pip install fastapi==0.162.0 httpx==0.28.1 httpx2==2.16.0 pytest==9.2.0 uvicorn==0.54.0
```

- `python3 --version` checks your Python; on macOS and Linux plain `python` may be missing or Python 2.
- `python3 -m venv .venv` creates the environment (`-m` runs a standard-library module as a program), and `source .venv/bin/activate` switches the terminal to it, usually showing `(.venv)`.
- `python -m pip install ...` installs into that environment. FastAPI, HTTPX and Uvicorn are MOKS's pinned versions and pytest the one I tested with. `httpx2` is not imported, but Starlette's test client warns without it.

Run `deactivate` to leave, and `source .venv/bin/activate` again in each new terminal.

MOKS keeps supported ranges in `pyproject.toml` (`fastapi>=0.115`) and exact pins in `requirements.txt` (`fastapi==0.162.0`). Its README installs both:

```bash
# working directory: the moks repository, inside an active virtual environment
cd backend
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
```

`-e .` installs MOKS in **editable** mode, so edits take effect without reinstalling, and `--no-deps` skips the ranges because the pins are installed. The full service and its tests also need PostgreSQL; the beginner examples do not.

## 3. Variables and basic data types

A **variable** is a name for a value, created with `=`. The basic types are `str` (text in quotes), `int` (whole numbers), `float` (decimals), `bool` (`True` or `False`) and `None` ("nothing here yet").

*Standalone teaching example.*

```python
# types_demo.py
service = "checkout"        # str
replicas = 3                # int
cpu_cores = 0.5             # float
healthy = True              # bool
owner = None                # NoneType

print(type(service), type(replicas), type(cpu_cores), type(healthy), type(owner))
replicas = replicas + 1
print(f"{service} has {replicas} replicas, healthy={healthy}")
print(f"CPU per replica: {cpu_cores:.2f} cores")
```

```text
$ python3 types_demo.py
<class 'str'> <class 'int'> <class 'float'> <class 'bool'> <class 'NoneType'>
checkout has 4 replicas, healthy=True
CPU per replica: 0.50 cores
```

`type(x)` shows what a value is. You never declared `replicas` as an integer; Python infers it, which is **dynamic typing**. An **f-string** (`f"..."`) replaces each `{...}` with a value, and `{cpu_cores:.2f}` formats two decimal places.

Text that looks like a number is still text; `int()`, `float()`, `str()` and `bool()` convert.

*Standalone teaching example.*

```python
# conversions.py
minutes_text = "30"
minutes = int(minutes_text)
print(minutes * 2)
print(minutes_text * 2)
print(str(minutes) + " minutes")
print(float("1.5"), bool(""), bool("no"))
```

```text
$ python3 conversions.py
60
3030
30 minutes
1.5 False True
```

`minutes_text * 2` repeats the string. `bool("")` is `False` and `bool("no")` is `True`, because any non-empty string counts as true (section 5).

`input()` returns what the person typed, always as a `str`:

*Standalone teaching example.*

```python
# ask.py
minutes = input("How many minutes? ")
print(type(minutes))
seconds = int(minutes) * 60
print(f"That is {seconds} seconds.")
```

Run it with `python3 ask.py` and type `45`:

```text
How many minutes? 45
<class 'str'>
That is 2700 seconds.
```

## 4. Collections: lists, tuples, dictionaries and sets

| Type | Written as | Use it when |
| --- | --- | --- |
| `list` | `["a", "b"]` | order matters and the contents change |
| `tuple` | `("a", "b")` | a small, fixed group of values |
| `dict` | `{"key": "value"}` | you look values up by a key |
| `set` | `{"a", "b"}` | you need unique values or fast "is it in here?" checks |

*Standalone teaching example.*

```python
# collections_demo.py
pods = ["cart-1", "cart-2", "catalogue-1"]
pods.append("payment-1")
print(pods[0], pods[-1], len(pods))

limits = ("500m", "512Mi")
cpu, memory = limits
print(cpu, memory)

restarts = {"cart-1": 0, "cart-2": 4}
restarts["catalogue-1"] = 1
print(restarts["cart-2"], restarts.get("payment-1", 0))

namespaces = {"shop", "moks", "shop"}
print(sorted(namespaces), "moks" in namespaces)
```

```text
$ python3 collections_demo.py
cart-1 payment-1 4
500m 512Mi
4 0
['moks', 'shop'] True
```

Positions start at 0, and `pods[-1]` counts from the end. `cpu, memory = limits` **unpacks** a tuple. `restarts.get("payment-1", 0)` returns a default instead of failing on a missing key. The set dropped the duplicate and has no order, hence `sorted()`.

*Standalone teaching example.*

```python
# iterate.py
restarts = {"cart-1": 0, "cart-2": 4}

for name in restarts:
    print("pod:", name)

for name, count in restarts.items():
    print(f"{name} restarted {count} times")
```

```text
$ python3 iterate.py
pod: cart-1
pod: cart-2
cart-1 restarted 0 times
cart-2 restarted 4 times
```

Looping over a dictionary gives its keys; `.items()` gives key and value pairs.

## 5. Conditions and loops

`if` runs a block when a condition is true, `elif` tries another condition, and `else` catches the rest.

*Standalone teaching example.*

```python
# conditions.py
restarts = 4
status = "Running"

if restarts == 0:
    print("healthy")
elif restarts < 5 and status == "Running":
    print("watch it")
else:
    print("investigate")

namespace = ""
if not namespace:
    namespace = "default"
print(namespace, status in ("Running", "Succeeded"))
```

```text
$ python3 conditions.py
watch it
default True
```

Comparisons are `==`, `!=`, `<`, `<=`, `>` and `>=`, combined with `and`, `or` and `not`. `if not namespace:` uses **truthiness**: `False`, `None`, `0`, `0.0`, `""` and empty collections count as false, everything else as true.

### Where this appears in MOKS

This function decides what kind of file a path points to:

*Actual project code* from [`backend/moks/rag/chunking.py`, lines 73–89](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/rag/chunking.py#L73-L89):

```python
# backend/moks/rag/chunking.py
def kind_of(path: str) -> str:
    p = path.lower()
    if p.startswith(("http://", "https://")):  # web pages are stored as Markdown-like text, whatever the URL ends in
        return "markdown"
    name = p.rsplit("/", 1)[-1]
    if name in ("dockerfile", "makefile", "jenkinsfile") or name.startswith("dockerfile."):
        return "code"
    ext = "." + name.rsplit(".", 1)[-1] if "." in name else ""
    if ext in MARKDOWN_EXT:
        return "markdown"
    if ext in YAML_EXT:
        return "yaml"
    if ext in CODE_EXT:
        return "code"
    if ext in DATA_EXT:
        return "data"
    return "text"
```

`path.lower()` makes `README.MD` and `readme.md` equal, `startswith` accepts a tuple of prefixes, `rsplit("/", 1)[-1]` keeps the file name, `... if ... else ...` is a **conditional expression**, and the first matching `return` wins. I ran it: `README.md` gives `markdown`, `deploy/values.yaml` gives `yaml`, `Dockerfile` and `app.py` give `code`, and `notes` gives `text`.

### for and while loops, break and continue

A `for` loop runs once per item and a `while` loop while its condition holds; `continue` skips to the next round and `break` leaves.

*Standalone teaching example.*

```python
# loops.py
pods = {"cart-1": 0, "cart-2": 4, "catalogue-1": 2, "payment-1": 7}

for name, restarts in pods.items():
    if restarts == 0:
        continue
    if restarts > 5:
        print("stop: crash loop in", name)
        break
    print(name, "restarted", restarts, "times")

attempt = 1
while attempt <= 3:
    print("attempt", attempt)
    attempt += 1
```

```text
$ python3 loops.py
cart-2 restarted 4 times
catalogue-1 restarted 2 times
stop: crash loop in payment-1
attempt 1
attempt 2
attempt 3
```

`cart-1` was skipped by `continue` and the loop stopped at `payment-1`. Without `attempt += 1` the `while` loop would never end.

### Comprehensions, after ordinary loops

A **comprehension** builds a collection in one expression, a shorter form of a loop that appends.

*Standalone teaching example.*

```python
# comprehensions.py
pods = {"cart-1": 0, "cart-2": 4, "catalogue-1": 2}

restarted = []
for name, count in pods.items():
    if count > 0:
        restarted.append(name)
print(restarted)

print([name for name, count in pods.items() if count > 0])
print(sorted({name.split("-")[0] for name in pods}))
```

```text
$ python3 comprehensions.py
['cart-2', 'catalogue-1']
['cart-2', 'catalogue-1']
['cart', 'catalogue']
```

Read `[name for name, count in pods.items() if count > 0]` like the loop above it; curly braces build a set instead. MOKS uses a set comprehension to clean a comma-separated setting:

*Actual project code* from [`backend/moks/config.py`, lines 191–193](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/config.py#L191-L193):

```python
# backend/moks/config.py
    @property
    def bootstrap_admin_set(self) -> set[str]:
        return {e.strip().lower() for e in self.bootstrap_admins.split(",") if e.strip()}
```

Given `" A@x.com, ,b@x.com"` it returned `{'a@x.com', 'b@x.com'}`. If a comprehension needs more than one `if` or nested loops, write an ordinary loop.

**Practice:** from `{"web": 2, "api": 0, "worker": 5}`, print the services with no replicas with a loop, then with a comprehension.

## 6. Functions

A **function** is a named, reusable block defined with `def`. Its **parameters** are the names in brackets, the values you pass are **arguments**, and `return` sends a value back.

*Standalone teaching example.*

```python
# functions_demo.py
def window_label(minutes, unit="minutes"):
    return f"last {minutes} {unit}"


print(window_label(30))
print(window_label(2, "hours"))
print(window_label(unit="days", minutes=7))


def show_label(minutes):
    print(f"last {minutes} minutes")


result = show_label(15)
print(result)
```

```text
$ python3 functions_demo.py
last 30 minutes
last 2 hours
last 7 days
last 15 minutes
None
```

`unit="minutes"` is a **default value**. Arguments can be **positional** (`window_label(2, "hours")`) or **keyword** (`window_label(unit="days", minutes=7)`). `show_label` only prints, so it returns `None`: **printing shows a value to a person; returning hands it to the calling code.**

### Where this appears in MOKS

This turns "the last 30 minutes" in a question into a number:

*Actual project code* from [`backend/moks/api/investigations.py`, lines 37–42](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/api/investigations.py#L37-L42):

```python
# backend/moks/api/investigations.py
def window_from_question(question: str) -> int | None:
    m = _WINDOW.search(question)
    if not m:
        return None
    n, unit = int(m.group(1)), m.group(2).lower()
    return n * (1440 if unit.startswith("d") else 60 if unit.startswith("h") else 1)
```

`_WINDOW` is a **regular expression** (from the `re` module) matching phrases like "past 2 hours", and `m.group(1)` is the number as text. I ran it: "...in the last 30 minutes" gives `30`, "...in the past 2 hours" gives `120`, and "why is checkout slow?" gives `None`, so the caller uses the default window.

### The mutable default argument mistake

A default value is created **once**, when Python reads the `def` line. For a list or dictionary that is a trap:

*Standalone teaching example.*

```python
# mutable_default.py
def add_tag(tag, tags=[]):
    tags.append(tag)
    return tags


print(add_tag("prod"))
print(add_tag("eu"))


def add_tag_fixed(tag, tags=None):
    if tags is None:
        tags = []
    tags.append(tag)
    return tags


print(add_tag_fixed("prod"))
print(add_tag_fixed("eu"))
```

```text
$ python3 mutable_default.py
['prod']
['prod', 'eu']
['prod']
['eu']
```

Every call shares one list. The fix defaults to `None` and creates a new list inside. MOKS's Pydantic models use `Field(default_factory=list)` for the same reason, as in `GroupIn` in `backend/moks/api/investigations.py`.

**Practice:** write `to_seconds(amount, unit="m")` for `"s"`, `"m"` and `"h"`, and call it positionally and by keyword.

## 7. Modules and imports

Every `.py` file is a **module**, and `import` loads one. A folder of modules with an `__init__.py` is a **package**.

*Standalone teaching example.* Save both files in the same folder.

```python
# windows.py
UNITS = {"m": 1, "h": 60, "d": 1440}


def to_minutes(amount, unit):
    return amount * UNITS[unit]


if __name__ == "__main__":
    print("running windows.py directly:", to_minutes(2, "h"))
```

```python
# report.py
import json
from pathlib import Path

import windows
from windows import to_minutes

print(windows.to_minutes(1, "d"), to_minutes(30, "m"))
print(json.dumps({"file": Path("report.py").name, "module": windows.__name__}))
```

```text
$ python3 windows.py
running windows.py directly: 120
```

```text
$ python3 report.py
1440 30
{"file": "report.py", "module": "windows"}
```

`import windows` gives you the module as `windows`; `from windows import to_minutes` copies one name in. Standard-library imports usually come first, then third-party, then your own. `__name__` is `"__main__"` in the file you run directly and the module's name when imported, so the guarded block ran for `windows.py` and was skipped when `report.py` imported it.

## 8. Files, JSON and configuration

A **context manager**, used with `with`, sets something up and tidies up afterwards even after an error; for files, that means closing them. `pathlib.Path` represents paths, joined with `/`. `json.dumps()` turns Python values into JSON text (**serialization**) and `json.loads()` or `json.load()` turns it back.

*Standalone teaching example.* It writes only inside a temporary folder that is deleted at the end.

```python
# files_and_json.py
import json
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as folder:
    path = Path(folder) / "investigation.json"
    record = {"question": "Why is checkout slow?", "minutes": 30, "namespaces": ["shop"], "done": False}

    path.write_text(json.dumps(record, indent=2), encoding="utf-8")
    print(path.name, path.suffix, path.exists())

    with open(path, encoding="utf-8") as handle:
        loaded = json.load(handle)

    print(loaded["minutes"] + 5, loaded["done"])
    print(json.dumps({"ok": True, "owner": None}))

print(path.exists())
```

```text
$ python3 files_and_json.py
investigation.json .json True
35 False
{"ok": true, "owner": null}
False
```

`TemporaryDirectory()` deletes its folder when the block ends, hence the final `False`. `write_text` opens, writes and closes in one call. After `json.load`, `loaded["minutes"]` is an `int` again, and Python's `True` and `None` became JSON's `true` and `null`.

**Environment variables** carry settings that differ between laptop and server. `os.environ.get(name, default)` returns a string or the default.

### Where this appears in MOKS

MOKS stores only a *reference* to a credential, such as "the environment variable `MOKS_CRED_PROM`" or "the file `prom/token`", and looks up the value when a connector needs it:

*Actual project code* from [`backend/moks/connectors/base.py`, lines 38–62](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/connectors/base.py#L38-L62):

```python
# backend/moks/connectors/base.py
def resolve_credential(ref: dict[str, Any] | None) -> str | None:
    """Resolve a credential reference to its secret value. Values never leave the process:
    they are not stored in the database, logged, audited, returned by the API or put in prompts.

    {"type": "env", "name": "MOKS_CRED_X"}       -> environment variable (from a Kubernetes Secret)
    {"type": "file", "path": "prom/token"}       -> file under MOKS_CREDENTIALS_DIR (mounted Secret)
    """
    if not ref or ref.get("type") in (None, "none"):
        return None
    kind = ref.get("type")
    if kind == "env":
        name = str(ref.get("name", ""))
        if not name.startswith("MOKS_CRED_"):
            raise ConnectorError("config", "environment credential names must start with MOKS_CRED_")
        value = os.environ.get(name)
        if value is None:
            raise ConnectorError("config", f"credential environment variable {name} is not set")
        return value.strip()  # a value made with `echo` or from a file ends in a newline, which is an illegal header
    if kind == "file":
        path = resolve_credential_path(ref)
        try:
            return path.read_text().strip()
        except OSError as exc:
            raise ConnectorError("config", f"credential file {path} is not readable ({type(exc).__name__})") from None
    raise ConnectorError("config", f"unsupported credential reference type {kind!r}")
```

The triple-quoted **docstring** documents the function. Only `MOKS_CRED_` names are allowed, so a stored reference cannot point at an unrelated variable. `strip()` removes a trailing newline that would make an illegal HTTP header. File references must resolve under one folder. Error messages name the variable or file, never the value.

**Common mistake:** printing or logging a configuration dictionary that contains a password. Print whether a secret is set, never its value.

**Practice:** write three pods to `pods.json` inside a `TemporaryDirectory`, read the file back, and print how many pods it holds.

## 9. Errors and exceptions

When something goes wrong, Python raises an **exception**; unhandled, it stops the program with a **traceback**. Early ones you will meet: `TypeError` (wrong kind of value), `KeyError` (no such key) and `ValueError` (right type, wrong value, as in `int("thirty")`).

*Standalone teaching example.*

```python

try:
    total = pod["restarts"] + 1
except TypeError as exc:
    print("TypeError:", exc)

try:
    owner = pod["owner"]
except KeyError as exc:
    print("KeyError:", exc)

try:
    minutes = int("thirty")
except ValueError as exc:
    print("ValueError:", exc)
```

```text
$ python3 common_errors.py
TypeError: can only concatenate str (not "int") to str
KeyError: 'owner'
ValueError: invalid literal for int() with base 10: 'thirty'
```

`try:` runs a block; if the exception named in `except` happens, Python jumps there, and `as exc` gives you the object. Naming specific exceptions keeps unexpected problems visible. `else` runs only when nothing was raised, and `finally` runs every time, which makes it the place for clean-up:

*Standalone teaching example.*

```python
# read_restarts.py
def read_restarts(pod):
    try:
        restarts = int(pod["restarts"])
    except KeyError:
        print("no restart count reported")
        return None
    except ValueError:
        print(f"not a number: {pod['restarts']!r}")
        return None
    else:
        print("parsed cleanly")
        return restarts
    finally:
        print("checked", pod.get("name", "unknown pod"))


print(read_restarts({"name": "cart-1", "restarts": "4"}))
print(read_restarts({"name": "cart-2", "restarts": "many"}))
print(read_restarts({"name": "cart-3"}))
```

```text
4
not a number: 'many'
checked cart-2
None
no restart count reported
checked cart-3
None
```

`finally` printed "checked ..." although every branch returned. `!r` shows a value's **representation**, with quotes around strings.

## 10. Type hints

**Type hints** say what type a value should be: `def window_from_question(question: str) -> int | None:` takes a string and returns an integer or `None`.

*Standalone teaching example.*

```python
# hints_demo.py
def summarise(pods: list[str], restarts: dict[str, int], owner: str | None = None) -> str:
    total = 0
    for name in pods:
        total += restarts.get(name, 0)
    who = owner or "nobody"
    return f"{len(pods)} pods, {total} restarts, owner: {who}"


print(summarise(["cart-1", "cart-2"], {"cart-2": 4}))

```

```text
1 pods, 0 restarts, owner: platform team
```

`list[str]` is a list of strings, `dict[str, int]` a dictionary of string keys and integer values, `str | None` an **optional** string (Python 3.10+; older code writes `Optional[str]`), and `-> str` the return type.

Python ignores hints at run time:

*Standalone teaching example.*

```python

print(add_minutes("30", "15"))
```

```text
3015
```

## 12. Calling APIs over HTTP

An HTTP client sends a **request** with a method (`GET` reads, `POST` usually creates or triggers) and a path, and gets a **response** with a **status code**: `2xx` success, `4xx` a wrong request (401 not signed in, 404 not found, 422 invalid data, 429 too many requests), `5xx` a server failure. MOKS uses **HTTPX**, which can swap the network for a **mock transport**, so these examples never leave your computer.

*Standalone teaching example.*

```python
# call_api.py
import httpx


def fake_server(request: httpx.Request) -> httpx.Response:
    if request.url.path == "/pods":
        return httpx.Response(200, json={"pods": [{"name": "cart-1", "restarts": 0}, {"name": "cart-2", "restarts": 4}]})
    return httpx.Response(404, json={"error": "not found"})


client = httpx.Client(base_url="http://cluster.local", transport=httpx.MockTransport(fake_server), timeout=5.0)

response = client.get("/pods")
print(response.status_code)
for pod in response.json()["pods"]:
    print(pod["name"], pod["restarts"])

missing = client.get("/nodes")
print(missing.status_code, missing.is_success)
try:
    missing.raise_for_status()
except httpx.HTTPStatusError as exc:
    print("HTTP error:", exc.response.status_code)
```

```text
$ python3 call_api.py
200
cart-1 0
cart-2 4
404 False
HTTP error: 404
```

`timeout=5.0` gives up after five seconds; always set one. `response.json()` parses the body. A 404 is still a *response*, and HTTPX raises for it only if you call `raise_for_status()`. A **transport error** is different: no response arrived at all.

### Where this appears in MOKS

Every connector goes through one wrapper, `BoundedHttp`, which classifies responses that did arrive:

*Actual project code* from [`backend/moks/connectors/base.py`, lines 176–185](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/connectors/base.py#L176-L185):

```python
# backend/moks/connectors/base.py
        if status in (401, 403):
            raise ConnectorError("auth" if status == 401 else "forbidden", f"{self.connector_type} rejected the credentials (HTTP {status})")
        if 300 <= status < 400:
            raise ConnectorError("bad_request", f"{self.connector_type} redirected to {headers.get('location', 'another address')}; put the final address in base_url")
        if status == 404:
            raise ConnectorError("not_found", f"{self.connector_type} endpoint not found (HTTP 404); check the base URL/path prefix")
```

`300 <= status < 400` is a chained comparison. Only 5xx errors are `retryable=True`, because a 401 or 404 fails the same way next time; rate limits (429) are handled just above and never retried.

Retrying a `GET` is safe. Retrying a `POST` that may already have succeeded could create something twice. Requests safe to repeat are **idempotent**, and MOKS retries only those:

*Actual project code* from [`backend/moks/connectors/base.py`, lines 135–150](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/connectors/base.py#L135-L150):

```python
# backend/moks/connectors/base.py
    async def request_json(self, operation: str, method: str, path: str, *, params: Any = None,
                           data: Any = None, idempotent: bool = True) -> Any:
        attempts = 1 + (self.limits.retries if idempotent else 0)
        start = time.monotonic()
        last: ConnectorError | None = None
        for attempt in range(attempts):
            try:
                result = await self._once(method, path, params, data)
                CONNECTOR_REQUESTS.labels(self.connector_type, operation, "ok").inc()
                CONNECTOR_LATENCY.labels(self.connector_type, operation).observe(time.monotonic() - start)
                return result
            except ConnectorError as exc:
                last = exc
                if not exc.retryable or attempt == attempts - 1:
                    break
                await asyncio.sleep(min(2.0, 0.3 * (3 ** attempt)))
```

`attempts` is 3 by default, or 1 for a non-idempotent request. The loop returns on the first success and stops on a non-retryable error or the last attempt, waiting 0.3 then 0.9 seconds (capped at 2) between tries, which is **backoff**. With a mock that always answers 503, an idempotent request was sent 3 times and an `idempotent=False` one once; both ended with `unavailable: demo returned HTTP 503: overloaded`.

**Common mistake:** retrying everything. Retry only idempotent requests, only for errors that might pass (timeouts, connection failures, 5xx), with a limit and a growing delay.

**Practice:** add a `/nodes` route to `fake_server` that returns two nodes, and print their names.

## 13. Building an API with FastAPI

**FastAPI** lets you write the server: it calls your Python functions when requests arrive. This small endpoint is modelled on MOKS's "start an investigation" route:

*Standalone teaching example.*

```python
# teaching_api.py
from fastapi import Depends, FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class QuestionIn(BaseModel):
    question: str = Field(min_length=3, max_length=200)
    minutes: int | None = Field(default=None, ge=5, le=1440)


def get_default_minutes() -> int:
    return 60


@app.get("/health")
def health() -> dict[str, str]:
    return {"status": "ok"}


@app.post("/questions", status_code=201)
def ask(body: QuestionIn, default_minutes: int = Depends(get_default_minutes)) -> dict:
    return {"question": body.question, "minutes": body.minutes or default_minutes}
```

`@app.get("/health")` and `@app.post("/questions", status_code=201)` register **routes**. ## 14. Understanding async and await

Normally each line finishes before the next starts (**synchronous** execution), so a program waiting on the network sits idle. An SRE tool waits a lot, for Kubernetes, Prometheus, Loki and language models.

`async def` defines a **coroutine**, a function that can pause. `await` marks where it waits for I/O and lets other coroutines run, and `asyncio` switches between them at each `await`. This is **cooperative**: a coroutine only gives way at an `await`.

*Standalone teaching example.* It takes about four seconds.

```python
# async_demo.py
import asyncio
import time


def fetch_sync(name):
    time.sleep(1)
    return f"{name} done"


async def fetch_async(name):
    await asyncio.sleep(1)
    return f"{name} done"


async def main():
    start = time.perf_counter()
    results = await asyncio.gather(fetch_async("pods"), fetch_async("logs"), fetch_async("metrics"))
    print(results, f"async: {time.perf_counter() - start:.0f}s")


start = time.perf_counter()
print([fetch_sync(n) for n in ("pods", "logs", "metrics")], f"sync: {time.perf_counter() - start:.0f}s")
asyncio.run(main())
```

```text
$ python3 async_demo.py
['pods done', 'logs done', 'metrics done'] sync: 3s
['pods done', 'logs done', 'metrics done'] async: 1s
```

Three `time.sleep(1)` calls take three seconds. `asyncio.gather(...)` runs three `asyncio.sleep(1)` waits at once, so they overlap in about one second, and `asyncio.run(main())` starts the event loop.

`async` helps only with *waiting*. A calculation never reaches an `await`, so nothing else runs, and any blocking call inside `async def` (`time.sleep`, a synchronous HTTP library, a long calculation) stalls *every* request the process serves. That is why MOKS's retry loop uses `await asyncio.sleep(...)`. boto3, which MOKS uses for Amazon Bedrock, has no async version, so those calls run in a thread:

*Simplified from project code* ([`backend/moks/llm/providers.py`, lines 363–375](https://github.com/mrjithendar/moks/blob/ef6908ac90730beac312813f539cd0bc57d94810/backend/moks/llm/providers.py#L363-L375)). Omitted: the boto3 client options, the message format and the handling of AWS error codes.

```python
# Simplified from backend/moks/llm/providers.py
def call():
    client = boto3.client("bedrock-runtime", region_name=region)
    return client.converse(modelId=self.cfg.model, messages=bedrock_messages)

try:
    data = await asyncio.wait_for(asyncio.to_thread(call), self.cfg.timeout_seconds + 5)
except asyncio.TimeoutError:
    raise LLMError("timeout", f"bedrock did not answer within {self.cfg.timeout_seconds}s") from None
```

`asyncio.to_thread(call)` runs the blocking function in a worker thread and returns something awaitable, and `asyncio.wait_for(..., seconds)` adds a time limit. Searching the backend for blocking calls in async code, I found `time.sleep` only in a synchronous migration helper, plus one small case: the OpenAI-compatible provider may read a small credential file with `path.read_text()` from async code, strictly a blocking read on the event loop.

**Common mistake:** calling a coroutine without `await` gives you a coroutine object, not a result (section 18).

```python
# backend/moks/llm/providers.py
    async def _post(self, url: str, body: dict, headers: dict[str, str]) -> dict:
        """Waits out rate limits and overload a little, because a provider's own Retry-After is the
        cheapest fix. Anything longer goes back to the caller as rate_limited."""
        async with httpx.AsyncClient(timeout=self.cfg.timeout_seconds, transport=self.transport) as c:
            for attempt in range(RETRIES + 1):
                try:
                    r = await c.post(url, json=body, headers=headers)
                except httpx.TimeoutException:
                    raise LLMError("timeout", f"{self.name} did not answer within {self.cfg.timeout_seconds}s") from None
                except httpx.TransportError as exc:
                    raise LLMError("unavailable", f"cannot reach {self.name} ({type(exc).__name__})") from None
                if r.status_code not in RETRY_STATUS or attempt == RETRIES:
                    break
                await asyncio.sleep(_wait(r, attempt))
```

It sends the conversation with headers holding the API key (from `resolve_credential`, section 8), makes up to three attempts on the "busy" codes in `RETRY_STATUS` (`{429, 500, 502, 503, 504, 529}`), honours `Retry-After` up to 10 seconds, and turns timeouts and transport failures into an `LLMError` with a `kind`. ### Preparing documents for retrieval

Before MOKS can answer from runbooks, it splits each document into **chunks** small enough to search and fit in a prompt:

```python
# backend/moks/rag/chunking.py
def chunk(path: str, text: str) -> list[ChunkPiece]:
    if not text.strip():
        return []
    k = kind_of(path)
    size, overlap = limits()
    spans, sections = _spans(text, k, size)
    out: list[ChunkPiece] = []
    for heading, a, b in sections:
        out.extend(_windows(text, spans[a:b], heading, size, overlap))
    return out
```

## 16. Following one feature end to end

A signed-in person asks "Why is checkout returning 502 errors in the last 30 minutes?", and the browser sends `POST /moks/api/investigations`:

```text
browser ── POST /moks/api/investigations {"question": "..."}
   │
uvicorn ── runs create_app() from moks/main.py
   │
middleware "observe" ── request id, Prometheus metrics, one JSON log line
   │
router (prefix /moks/api) ── create(body, request, ctx, db)
   ├─ get_db     one database session for this request
   ├─ get_auth   cookie → 401 · rate limit → 429 · CSRF/Origin → 403
   └─ CreateIn   Pydantic checks the body → 422
   │
start_investigation()
   ├─ per-user rate limit and queue limit → 429
   ├─ resolve_scope()          which environment and namespace
   ├─ RBAC check               → 403
   ├─ window_from_question()   "last 30 minutes" → 30
   └─ insert Investigation(status="queued"), first event, audit record
   │
serialize() → dict → JSON, HTTP 201
   ·
   · later, in a separate process
   ·
moks worker ── claim(): UPDATE … FOR UPDATE SKIP LOCKED ── runs the investigation
```

1. **Entry point.** `moks serve` runs Uvicorn with `moks.main:create_app`, which builds the app, adds the `observe` middleware and mounts every router under `/moks/api`.
2. **Dependencies.** `get_db` provides a session and `get_auth` the user; no session means 401.
3. **Validation.** Pydantic checks the body against `CreateIn`; a two-character question means 422.
4. **Main function.** `start_investigation` applies a per-user rate limit and a queue limit, resolves environment and namespace, checks permission, computes the window with `window_from_question`, and adds a `queued` `Investigation` row, a first progress event and an audit record.
5. **Response.** `serialize()` turns the row into a dictionary sent as JSON with 201, after `get_db` commits.
6. **Background work.** A separate `moks worker` claims the oldest queued row with PostgreSQL's `FOR UPDATE SKIP LOCKED`, so two workers never take the same one, then reads Kubernetes, Prometheus and Loki and calls a model if one is configured.

Python and `re` supply `window_from_question`, `serialize` and the checks; FastAPI the routing, dependencies and error bodies; Pydantic the validation; SQLAlchemy with asyncpg the row and session; and PostgreSQL, Kubernetes, Prometheus, Loki and the model provider are external services.

### Exercise 3

*Standalone teaching example.*

```python
# windows_parse.py
UNITS = {"m": 1, "h": 60, "d": 1440}


def parse_window(text: str) -> int | None:
    text = text.strip().lower()
    if len(text) < 2 or text[-1] not in UNITS:
        return None
    number = text[:-1]
    if not number.isdigit():
        return None
    return int(number) * UNITS[text[-1]]


if __name__ == "__main__":
    for sample in ("30m", "2h", "1d", " 2H ", "soon", "h", ""):
        print(repr(sample), parse_window(sample))
```

```text
$ python3 windows_parse.py
'30m' 30
'2h' 120
'1d' 1440
' 2H ' 120
'soon' None
'h' None
'' None
```

`text[-1]` is the last character and `text[:-1]` everything before it (**slicing**). `isdigit()` checks first, so `int()` cannot raise and no `try` is needed.

### Exercise 5

```python
# windows_api.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from windows_parse import parse_window

app = FastAPI()


class WindowIn(BaseModel):
    text: str = Field(min_length=1, max_length=20)


@app.post("/windows")
def windows(body: WindowIn) -> dict[str, int]:
    minutes = parse_window(body.text)
    if minutes is None:
        raise HTTPException(400, "use a number followed by m, h or d, such as 30m")
    return {"minutes": minutes}
```
