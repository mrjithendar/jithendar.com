The nine required topics became nine figures because crowded drawings were split so they stay readable on a phone. Each is 620 px wide.

**The SVGs and PNGs are not draw.io exports.** See `editorial-review.md`. To rebuild everything from `www/`:

```bash
python3 docs/knowledge-sharing/roboshop-ai/diagrams/build_diagrams.py
sh docs/knowledge-sharing/roboshop-ai/diagrams/render_png.sh
python3 docs/knowledge-sharing/roboshop-ai/verify_series.py ../../roboshop-ai
```

Component colours are the same in every figure: slate for the browser, indigo for the edge, blue for `ai-gateway`, violet for `moks`, teal for `mcp-server`, green for domain services, pink for model providers, amber for data stores, red for messaging and refusals. A dashed box means absent.
